# Среда проекта

## Репозиторий

- **GitHub:** https://github.com/ezikmutant/gorodovye
- **Ветка:** `main`
- **Что залито:** `app/` (база, каталог, витрина, тесты) и `ds/` (спецификация).

Остальное содержимое проекта — исследования, интервью, макетные материалы,
черновики и `_private!` — **не заливается**. Список ведётся наоборот
привычного: в `.gitignore` сначала запрещено всё, потом разрешено нужное.
Новая папка в проекте по умолчанию никуда не уедет.

## Как обновлять

Повторный запуск директивы `directive_handoff` — это обновление того же
репозитория, а не создание нового: правки в основную линию идут в `main`,
незаконченная итерация — в отдельную ветку.

Токен для пуша живёт у автора и в файлы проекта не попадает.
