# Городовые

Приложение про городские скульптуры: находишь фигурку на улице, отмечаешь
её в приложении, она попадает в альбом находок.

В этом репозитории — **база компонентов и её витрина**, то есть та часть,
которая уже собрана в коде. Экраны продукта по ней ещё не собраны.

## Что здесь лежит

| Папка | Что это |
|---|---|
| `app/lib/ds/` | база: токены и компоненты. Это и есть продукт этой работы |
| `app/lib/catalog/` | каталог компонентов: страница на каждый, матрица состояний, сниппет кода, песочницы с готовыми кусками экранов |
| `app/lib/showcase.dart` | витрина: всё разом, одним полотном — для быстрой сверки с макетом |
| `app/test/` | тесты, включая покадровую пробу движения (`motion_probe.dart`) |
| `ds/` | спецификация: основания, компоненты, движение, паттерны. Код написан по ней, и расхождения считаются ошибкой кода |

## Как запустить

Нужен Flutter 3.47 или новее.

```bash
cd app
flutter pub get

# витрина — всё разом
flutter run -d chrome -t lib/main.dart

# каталог компонентов
flutter run -d chrome -t lib/catalog_main.dart
```

## Как проверить

```bash
cd app
flutter analyze
flutter test

# движение покадрово, с числами
flutter test test/motion_probe.dart --plain-name проба
```

`flutter test` включает golden-тест витрины: если картинка разошлась
с эталоном, тест падает и кладёт разницу в `app/test/failures/`.

## С чем сверяться

Источник истины — макет в Figma; `ds/*.md` — его словесная запись, и там же
записано, почему принято то или иное решение. Начинать лучше с `ds/CONTRACT.md`.
