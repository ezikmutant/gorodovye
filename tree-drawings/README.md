# Рисунки на деревьях Москвы

Карта: <https://ezikmutant.github.io/gorodovye/tree-drawings/>

Все известные точки рисунков на деревьях в одном месте: официальная карта акции
«ПаркАрт» Мосприроды, рисунки Марины Кочневой в парке Фили и метки арт-объектов
OpenStreetMap посреди парков и лесов.

| Файл | Что это |
| --- | --- |
| `points.csv` | все точки — единственный источник, правки вносить сюда |
| `build.py` | собирает из `points.csv` два файла ниже |
| `points.geojson` | данные для карты (`index.html`) |
| `tree-drawings-moscow.kml` | список меток для Organic Maps, Google My Maps, «Моих карт» Яндекса |
| `index.html` | карта: MapLibre и подложка OpenFreeMap, как в «Городовых» |

## Organic Maps

Открыть на телефоне
<https://ezikmutant.github.io/gorodovye/tree-drawings/tree-drawings-moscow.kml>, скачать
и открыть файл в Organic Maps — появится список «Рисунки на деревьях Москвы». Цвета:
зелёные — официальная карта, фиолетовые — Фили, синие — рисунки по OSM, оранжевые —
метки OSM, которые надо проверить, красные — найденные на месте.

## Добавить точку

Дописать строку в `points.csv` и запустить:

```sh
python3 tree-drawings/build.py
```

Поля: `kind` — `official`, `fili`, `osm` или `check`; `found` — дата, когда рисунок
нашли на месте (тогда метка красная); `untitled` — `1`, если у рисунка нет названия;
`place` и `place_basis` — где точка и на чём это основано.

## Откуда данные

- **Официальная карта ПаркАрт** — конструктор Яндекс Карт, три версии 2022 года:
  [октябрь](https://yandex.ru/maps/?um=constructor%3A35ee50ff35841fd2d512dc0a5475fa0f27b50e254b42a5c91761a32bdb965c2c),
  [август](https://yandex.ru/maps/?um=constructor%3A9dd1d5a2fc182b8d14ffc34ba57264b8e085b5dacbabdf531b2ddbe332e07c84),
  [июнь](https://yandex.ru/maps/?um=constructor%3A8604de361032005efbab5c95976eedaa43539cc0fcd686ee3e44efad4449f5d8).
  Ссылки найдены в копиях страницы акции в веб-архиве; сайт mospriroda.ru отдаёт пустую
  страницу. Взята октябрьская версия (114 точек): в ранних те же рисунки, у нескольких
  чуть другие координаты.
- **Фили** — [карта About #Moscow](https://am.epishkin.com/fili), 2021: 16 точек без
  названий; два названия подставлены из меток OSM в 12 и 25 м.
- **OpenStreetMap** — `tourism=artwork` внутри парков и лесов Москвы, отобраны вручную из
  602 меток (остальные — скульптуры). В Измайлове три такие метки без подписи оказались
  в 6–12 м от рисунков с официальной карты, одна из них — «Египетский кот», проверенный
  на месте 24.10.2026.

После октября 2022 официальная карта не обновлялась. Где искать рисунки 2023 года
(больше 90 штук), сказано внизу карты.
