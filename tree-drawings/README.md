# Рисунки на деревьях Москвы

Карта: <https://ezikmutant.github.io/gorodovye/tree-drawings/> (работает, когда в настройках
репозитория включён GitHub Pages: Settings → Pages → `main` / `(root)`).

Все известные точки рисунков на деревьях в одном месте: официальная карта акции
«ПаркАрт» Мосприроды, рисунки Марины Кочневой в парке Фили, метки арт-объектов
OpenStreetMap посреди парков и лесов, места с Яндекс Карт. Плюс территории, где акция
проходила, — зелёными областями.

| Файл | Что это |
| --- | --- |
| `points.csv` | все точки — единственный источник, правки вносить сюда |
| `territories.geojson` | контуры территорий акции (из OSM) |
| `build.py` | собирает из них три файла ниже |
| `yandex-map.geojson` | точки и территории для импорта в Конструктор Яндекс Карт |
| `tree-drawings-moscow.kml` | список меток для Organic Maps (и Google My Maps) |
| `points.geojson` | данные для карты (`index.html`) |
| `index.html` | карта: MapLibre и подложка OpenFreeMap, как в «Городовых» |

## Цвета

| Цвет | Что значит |
| --- | --- |
| красный | рисунок найден на месте |
| зелёный | рисунок виден на фото в карточке места на Яндекс Картах |
| серый | официальная карта ПаркАрт, не проверено: часть рисунков не нашлась, часть координат сбита |
| фиолетовый | карта Филей (About #Moscow) |
| синий | в OpenStreetMap отмечен как рисунок |
| оранжевый | метка без подтверждения, что это рисунок на дереве, — проверить |
| тёмно-серый | искали на месте и не нашли |
| зелёная область | территория, где проходил ПаркАрт |

## Яндекс Карты

[Конструктор карт](https://yandex.ru/map-constructor/) → создать карту → «Импорт» →
файл `yandex-map.geojson`. Цвета взяты из палитры конструктора, у каждой метки есть
подпись и описание: автор, год, место, откуда точка и что показала сверка.

## Organic Maps

Открыть `tree-drawings-moscow.kml` на телефоне в Organic Maps — появится список
«Рисунки на деревьях Москвы».

## Добавить или поправить точку

Дописать или исправить строку в `points.csv` и запустить:

```sh
python3 tree-drawings/build.py
```

Поля:

- `kind` — откуда точка: `official`, `fili`, `osm`, `yandex` или `check`;
- `found` — дата, когда рисунок нашли на месте (метка станет красной);
- `confirmed` — `yandex-photo`, если рисунок виден на фото в Яндекс Картах (зелёная);
- `status` — `excluded`, если точку надо снять: на карты она не пойдёт, а в таблице останется;
- `status_note` — почему снята или что показала сверка по картам;
- `field_note` — что увидели на месте;
- `missing` — дата, когда рисунок искали на месте и не нашли (метка станет тёмно-серой);
- `untitled` — `1`, если у рисунка нет названия;
- `place`, `place_basis` — где точка и на чём это основано;
- `yandex`, `osm` — номер места на Яндекс Картах и метки в OSM.

## Сверка 26.10.2026

Каждую точку посмотрели на спутнике Яндекса и на схеме 2ГИС и сверили с тем, что стоит
в этом месте в OpenStreetMap. Правило: объект должен быть деревом.

Сняты 15 точек, причины — в `status_note`:

- пять рисунков сквера у ул. Туристская, 20 к1 — на официальной карте они стоят на крыше
  дома; вместо них на карте территория;
- три «мурала» в Кусково — стены здания «Экошкола Кусково»;
- метка на смотровой площадке Круглого пруда в Измайлове;
- метки, которые по 2ГИС и Яндекс Картам оказались среди скульптур: сад Музея славянской
  культуры в Лианозове, Пресненский парк, Свиблово, парк Никулинской аллеи.

Три точки официальной карты по 2ГИС и OSM стоят в пруду, а на спутнике — у самого
берега среди деревьев («Звёзды», «Алиса в стране чудес» в Кузьминках, «Дятел» в
Измайлове): они оставлены, в описании сказано, что координата сбита.

По Яндекс Картам: «Ёжик в тумане» в Измайлове есть там как место, в 2 м от точки
официальной карты, рисунок виден на фото. «Звёздная ночь» (Ван Гог в дупле, Измайлово)
есть только на Яндексе — добавлена. «Тоторо» в Восточном Измайлове есть на Яндексе без
фото — оставлен на проверку. Поиск Яндекса по названиям остальных рисунков ничего не
нашёл: обычно их там нет.

Поиск по 2ГИС автоматически недоступен (сайт закрыт от программ); 2ГИС использован только
как карта для сверки места.

## Территории

Список собран по пресс-релизам Мосприроды 2018–2023 годов. За 2024–2025 годы сведений
не нашлось.

- 2016–2019: Косинский, Измайловский, Терлецкий и Кусковский лесопарки (ВАО).
- С 2020: «Кузьминки-Люблино», «Царицыно», «Москворецкий», «Тушинский», «Алтуфьевский»,
  «Лианозовский», «Медведковский», усадьба Архангельское-Тюриково.
- С 2021: «Покровское-Стрешнево».
- 2022: ещё «Химкинский», «Долгие пруды», «Северный», «Жулебинский», природный комплекс
  № 100, «Битцевский лес»; и городские площадки — сквер у ул. Туристская, 20 к1, Девичье
  поле, сквер у театра танца «Гжель», бульвар Генерала Карбышева, 14, Краснохолмская
  набережная, 1 стр. 3, Фрунзенская набережная, 50 (седьмая площадка не названа).
- 2023: «Серебряный бор».

Границ в OSM не нашлось у «Жулебинского» и природного комплекса № 100 — их на карте нет.
«Серебряный бор» показан точкой, у «Москворецкого» — только часть, Крылатские холмы.
