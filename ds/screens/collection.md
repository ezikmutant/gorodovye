# Экран: Находки

**Секция:** Screens → Collection · **Мастер:** `Screen/Collection` `325:458` (UI → UI Kit screens)
**Матрица:** `State=default / empty` · **Слот:** `AlbumContent`
**Размер:** 375×812

Эмоциональное ядро продукта — альбом собранных городовых.

## Состав

| Слой | Что |
|---|---|
| StatusBar | `Theme=light` |
| CollectionHeader | «Находки» `DS/Display/4xl` + счётчик собранных |
| CollectionFilters / CollectionToolbar | фильтры и управление, слот `Tabs` |
| AlbumContent | слот: сетка `founded_object` в две колонки |
| EmptyState | стартовое состояние |
| Navbar | `Active=finds` |

## Состояния в секции

| Кадр | Что показывает |
|---|---|
| Частотное | шесть находок, сетка заполнена — как экран выглядит в обычной жизни |
| Одна находка | проверка, что сетка не разваливается на единственной карточке |
| Стартовое | `State=empty` — до первой находки |
| Загрузка | сетка из `founded_object State=skeleton` — заглушки в геометрии настоящих карточек |
| На развитие | фильтры и сортировка, отложены: «для MVP контента мало» |

## Штампики на карточках

Источник правды — фрейм **«Документация: InkStamp»** (`325:2069`, страница UI).

| Правило | Как есть |
|---|---|
| Где живёт | только на карточках коллекции |
| Как размещён | абсолютным позиционированием в обёртке `CardCell`, поверх карточки |
| Координата и поворот | задаются **на каждой карточке** |
| Цвет | из палитры `ink`: красный, синий, зелёный, графитовый |
| Форма | подменой инстанса: `round` / `signature` / `block` |
| Уникальность | у каждой карточки свой — совпадений быть не должно |

**`InkStamp` и `FoundBadge` — разные вещи, и их нельзя путать.** `FoundBadge` живёт в шторке, всегда выглядит одинаково и сообщает факт: «НАЙДЕНО · дата». `InkStamp` живёт в альбоме, у каждой карточки свой, и работает украшением коллекции, а не статусом. На одном экране они не встречаются.

**Ручная постановка — это способ примерки в Figma, а не поведение продукта.** В макете координата, поворот, цвет и форма выставлены руками, чтобы посмотреть, как это живёт на шести карточках. В коде штамп ставится **алгоритмом**: рандомизация по правилам из `patterns.md`, сид от id находки, выпавшие значения закрепляются за ней навсегда.

Из этого следует требование к разработке: параметры штампа сохраняются вместе с находкой, а не пересчитываются при каждом открытии альбома. Иначе коллекция будет каждый раз выглядеть иначе и перестанет ощущаться своей.

## Решения

**Карточки стоят ровно, наклоняется штамп.** Разнобой живёт в отметке о находке, а сетка остаётся сеткой — иначе альбом читается как беспорядок, а не как коллекция.

**Несобранные не показываются вообще** — ни силуэтом, ни пустой ячейкой. Счётчик говорит, сколько собрано, и молчит о том, сколько осталось: прогресс без дефицита (PRD).

**Фильтры заложены, но выключены.** При шести находках фильтр — управляющий элемент без задачи. Компонент готов и включается, когда коллекция дорастёт до объёма, где глазами уже не найти.
