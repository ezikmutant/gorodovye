# Служебные экраны

**Секция:** Screens → Service (`401:2634`)
**Актуально на:** 2026-08-12

Состояния, которых требует уличное приложение: отказ в доступе, потеря связи, загрузка. Собраны по итогам UX-аудита.

## Принцип: полный экран только там, где раздел не работает

| Ситуация | Форма | Почему |
|---|---|---|
| Нет разрешения на гео или камеру | полноэкранный | без доступа раздел не работает вообще, и человеку надо объяснить, зачем он нужен |
| Нет сети | плашка поверх контента | продукт продолжает работать: находки лежат локально, карта показывает загруженное. Полноэкранная ошибка врала бы |
| Не удалось сохранить | плашка с действием `Кнопка=true` | нужен путь назад, а не сообщение |
| Загрузка | скелетон в структуре контента | форма будущего содержимого видна сразу |
| Отмена находки | подмена плавающей кнопки | человек остаётся там же, где был; окно живёт 5 секунд и уходит само |

## Кадры

| Кадр | Что |
|---|---|
| `Гео запрещено` | «Не видим, где ты» + спящий городовой. Кнопки: «Открыть настройки» и «Листать карту без геолокации» — отказ не превращается в тупик |
| `Камера запрещена` | «Камера выключена» + пояснение, что снимать необязательно и находку можно отметить без камеры |
| `AR — наводим камеру` | тёмный экран, три точки, «Наводим камеру…» |
| `Карта без сети` | `ToastError` без действия, `msg-offline-map` |
| `Альбом без сети` | `ToastError` без действия, `msg-offline-album` |
| `Не удалось сохранить` | `ToastError` с «Повторить», вплотную над кнопкой действия |
| `Шторка — загрузка` | `Sheet-skeleton` поверх затемнённой карты |
| `Альбом — загрузка` | сетка `founded_object State=skeleton` |
| `Что это — заготовка` | три блока авторского текста, ник в телеграме — ссылка `text-link` |
| `Отмена находки` | шторка после «Нашёл!»: остаётся открытой, штамп стоит, внизу `BottomAction Action=undo` |

## Решения

**Отказы говорят фирменным голосом.** «Не видим, где ты», «Снимать городовых — необязательная часть» — служебные экраны это ровно то место, где продукт с тёплым тоном обычно начинает разговаривать как банкомат. Здесь тон держится.

**У отказа всегда есть второй выход.** Без геолокации — листать карту руками, без камеры — вернуться и отмечать находки. Экран не запирает.

**Скелетон карты не рисуем** — тайлы грузит SDK.

**«Убрать из находок», а не «Отменить».** Человек ничего не отменяет: находка состоялась, штамп поставлен. Он решает, оставлять ли запись в своей коллекции. «Отменить» сразу после награды читается как «мы её не засчитали» — продукт отбирает то, что только что дал.

**Затемнение на всех экранах одинаковое** — `map-dim-overlay` с `surface-dim`. До 2026-08-12 на кадре «Шторка — загрузка» оно было собрано иначе: `surface-overlay` при `opacity` узла 0.4, отчего один и тот же экран выглядел на четверть темнее остальных.

## Долг

Тексты экрана «Что это» — черновые, помечены плашкой прямо в макете. Заменяются авторским текстом.

Долг по плашке ошибки закрыт 2026-08-12: она перестала быть локальной вёрсткой и стала компонентом `ToastError` со свойством `Кнопка`; набор `Toast`, который никогда не использовался, удалён.
